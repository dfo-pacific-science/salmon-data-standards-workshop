This lesson follows the included NuSEDS Fraser Coho sample through the entire Salmon Data Package workflow: inspect the data, build a package, preserve context, review meanings, export EML, and preview a catalog deposit. Everyone uses the same 30-row sample; no personal dataset is required. The common pathway is FAIR publication: preserve context, link selected meanings to shared definitions, export validated EML 2.2, and prepare a guarded upload to an EML-aware catalog such as KNB. Learners can go further by proposing missing shared terms or by planning how an organizational vocabulary or ontology will be governed and mapped to the Salmon Domain Ontology as a shared interoperability layer.

Code-driven activities include R and Python lanes, and spreadsheet-specific subsections work with the same standard package files without requiring code. Spreadsheet participants receive a facilitator-generated package from that same sample. The workshop pins R `metasalmon` to `v0.5.0` and Python `metasalmonpy` to `v0.4.0`; Session 4 explicitly describes the Python semantic-review capability gap. An optional bring-your-own-dataset activity follows the core workflow near the end, with a separate output folder so the shared example remains available.
