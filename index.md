Follow the **NuSEDS Fraser Coho 2023–2024 dataset** through a complete, six-hour workshop. All participants use the same 173 rows and 14 columns, beginning with human interpretation and ending with a test catalog publication exercise. No personal dataset is needed.

Draw the relationships behind the observations, write and peer-review a data dictionary, build a [Salmon Data Package](glossary.html#salmon-data-package), and compare your mappings with recorded [AI](glossary.html#ai) suggestions. Then describe codes and unresolved terms, validate the package, export [EML](glossary.html#eml), and inspect a [KNB](glossary.html#knb) Test Node record. The reference package remains a technical draft pending Bruno and Tom's domain review.

Spreadsheet, R, and Python learners work with the same source, worksheets, and package checkpoints. The required AI comparison uses supplied outputs; live AI calls are optional and no paid service or account is required for the core activities.

Start with [Setup](setup.html) and the [downloadable workshop kit](files/fraser-coho-workshop.zip). Keep the [Glossary](glossary.html) and [Field reference](field-reference.html) open as you work. The [Reference page](reference.html#teaching-record) records the teaching catalog's status and the distinction between technical checks, domain review, and publication authority.
